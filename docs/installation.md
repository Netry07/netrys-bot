## Состав программы

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа: приём сообщений, `/summary`, реакции на обращения, автокомментарии, запуск бота |
| `wheel.py` | Колесо удачи: тиры, коэффициенты, пакетное добавление, рисование и отправка GIF |
| `requirements.txt` | Список зависимостей Python |
| `.env` | Секреты (создаётся вручную, в репозиторий не попадает) |
| `messages.db` | База SQLite, создаётся ботом при первом запуске |

## Требования

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| Операционная система | Linux, Windows или macOS | Linux (Debian/Ubuntu, Arch) |
| Python | 3.10 | 3.12 |
| Оперативная память | 256 МБ | 512 МБ |
| Свободное место на диске | 100 МБ | 500 МБ (база растёт вместе с чатами) |
| Сеть | Исходящий HTTPS (порт 443) | Стабильное соединение |
| Шрифт с кириллицей | Любой TTF с поддержкой кириллицы | DejaVu Sans Bold |

Бот обращается к двум внешним адресам: `api.telegram.org` (Telegram) и `openrouter.ai` (нейросеть). Входящие порты открывать не нужно.

> ℹ️ Шрифт нужен только для подписей на колесе. Без него колесо рисуется без названий, а выпавший пункт всё равно приходит текстом. Шрифт ищется автоматически (DejaVu, Noto, Liberation) или берётся из переменной `WHEEL_FONT`.

## Настройка

### Переменные окружения

Бот читает их из файла `.env` в папке запуска.

| Переменная | Обязательная | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `OPENROUTER_API_KEY` | Да | Ключ OpenRouter для резюме и реплик |
| `WHEEL_FONT` | Нет | Путь к TTF-шрифту для подписей на колесе |

Пример файла `.env`:

```text
TELEGRAM_BOT_TOKEN=123456:ABC-DEF
OPENROUTER_API_KEY=sk-or-xxxxxxxx
WHEEL_FONT=/usr/share/fonts/TTF/DejaVuSans-Bold.ttf
```

> 🔐 Не публикуйте `.env`. Если токен попал в чужие руки, перевыпустите его командой `/revoke` в BotFather.

### Параметры в коде

Эти значения меняются прямо в `bot.py`:

| Параметр | Значение по умолчанию | Что делает |
|---|---|---|
| `MODEL` | `openai/gpt-oss-120b:free` | Модель OpenRouter для резюме и реплик |
| `BOT_USERNAME` | `netrys_bot` | Username бота без `@`; по нему бот узнаёт, что к нему обратились |
| `MAX_MESSAGES` | `1000` | Сколько последних сообщений хранить на чат |
| `AUTO_COMMENT_EVERY` | `50` | Через сколько сообщений бот вставляет реплику |
| `DB_PATH` | `messages.db` | Путь к файлу базы |

> ⚠️ Если вы создали своего бота с другим username, обязательно поменяйте `BOT_USERNAME`, иначе бот не будет реагировать на обращения к нему.

Параметры колеса (коэффициенты по умолчанию, лимиты) описаны в [Справке](reference.md#параметры-колеса).

## Установка

1. Склонируйте репозиторий и перейдите в папку:
   ```bash
   git clone git@github.com:Netry07/netrys-bot.git
   cd netrys-bot
   ```
   **Результат:** в папке есть `bot.py`, `wheel.py` и `requirements.txt`.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
   **Результат:** в начале строки терминала появилось `(.venv)`.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   **Результат:** команда завершилась без ошибок. Проверка: `python -c "import telegram, PIL; print('ok')"` выводит `ok`.
4. Создайте файл `.env` (см. выше).
5. Отключите режим приватности в BotFather: `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** → **Turn off**. Если бот уже был в группе, удалите его и добавьте заново.
6. (По желанию) задайте список команд через `/setcommands` в BotFather, чтобы они появились в меню чата:
   ```text
   wheel - Меню колеса удачи
   spin - Крутить колесо
   tierlist - Тир-лист и шансы
   addgame - Добавить пункт или список
   setweights - Коэффициенты тиров
   weights - Показать коэффициенты
   wheels - Список колёс, переключение
   newwheel - Создать новое колесо
   wheelstats - Статистика колеса
   newevening - Новый вечер, сбросить выпавшие
   summary - Резюме переписки
   count - Сколько сообщений запомнено
   cancel - Отменить текущий диалог
   help - Справка
   ```

## Запуск в фоне

Команда `python bot.py` держит бота живым, пока открыт терминал. Чтобы бот работал постоянно:

| Способ | Команда | Когда подходит |
|---|---|---|
| `tmux` | `tmux new -s bot`, затем `python bot.py`, выход `Ctrl+B`, `D` | Есть `tmux`, права администратора не нужны |
| `nohup` | `nohup .venv/bin/python bot.py >> bot.log 2>&1 &` | Простой запуск без дополнительных программ |
| `systemd` | см. ниже | Нужен автозапуск после перезагрузки и права администратора |

Пример службы `systemd` (файл `/etc/systemd/system/netrys-bot.service`):

```ini
[Unit]
Description=Netrys Telegram bot
After=network-online.target

[Service]
WorkingDirectory=/home/USER/netrys-bot
ExecStart=/home/USER/netrys-bot/.venv/bin/python bot.py
Restart=on-failure
RestartSec=5
User=USER

[Install]
WantedBy=multi-user.target
```

Включение: `sudo systemctl enable --now netrys-bot`. Логи: `journalctl -u netrys-bot -n 50`. Вместо `USER` подставьте имя пользователя.

> ⚠️ Одновременно должен работать только один экземпляр бота. Второй вызовет ошибку `Conflict: terminated by other getUpdates request`.

## Проверка

Контрольные примеры, по которым видно, что всё настроено:

| Проверка | Действие | Признак нормы |
|---|---|---|
| Запуск | `python bot.py` | В терминале `Бот запущен.`, нет traceback |
| Связь с Telegram | `/start` в чате с ботом | Приходит приветствие со списком команд |
| База данных | `/count` в группе после пары сообщений | «📊 Запомнено сообщений: N (макс. 1000)», где N больше нуля |
| Нейросеть | `/summary` → «📝 50 сообщений» → «📄 Обычное» | Приходит «📋 Резюме …» |
| Колесо | `/spin` | Анимация и результат с шансом |

Если признак нормы не наблюдается, найдите симптом в разделе [FAQ и неисправности](faq.md#неисправности).

## Обновление

```bash
cd netrys-bot
git pull
source .venv/bin/activate
pip install -r requirements.txt
```

Затем перезапустите бота: остановите старый процесс и запустите заново. База `messages.db` при обновлении сохраняется, новые таблицы колеса создаются автоматически.

## Сообщения при установке

| Сообщение | Причина | Что делать |
|---|---|---|
| `KeyError: 'TELEGRAM_BOT_TOKEN'` или `KeyError: 'OPENROUTER_API_KEY'` | Переменная не найдена | Проверьте, что `.env` лежит в папке, откуда запускается бот, и имена написаны точно |
| `ModuleNotFoundError: No module named 'PIL'` (или `telegram`) | Зависимости не установлены в этом окружении | Активируйте `.venv` и выполните `pip install -r requirements.txt` |
| `Command 'pip' not found` | Вы вне виртуального окружения | Активируйте `.venv`: `source .venv/bin/activate` |
| `Conflict: terminated by other getUpdates request` | Запущено два экземпляра бота | Остановите лишний процесс (`ps -eo pid,cmd \| grep bot.py`) |
| `Не найден шрифт с кириллицей — подписи на колесе отключены` | В системе нет подходящего шрифта | Установите DejaVu или задайте `WHEEL_FONT` |
| `InvalidToken: The token ... was rejected by the server` при старте | Неверный или отозванный токен | Проверьте токен в `.env`, при необходимости получите новый в BotFather |
