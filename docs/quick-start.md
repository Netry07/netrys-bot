Эта страница нужна, чтобы запустить Нетриса с нуля. Каждый шаг заканчивается проверкой: если результат другой, переходите к [FAQ и неисправностям](faq.md). Полное описание настройки — в разделе [Установка и настройка](installation.md).

> **Условие:** на компьютере или сервере установлены Python 3.10 или новее и Git.

## Шаг 1. Получите токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Задайте имя и username бота (username должен заканчиваться на `bot`).

**Результат:** BotFather пришлёт токен вида `123456:ABC-DEF...`. Сохраните его и никому не показывайте.

## Шаг 2. Получите ключ OpenRouter

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai).
2. Создайте ключ в разделе API Keys.

**Результат:** у вас есть ключ вида `sk-or-...`.

## Шаг 3. Скачайте код и поставьте зависимости

```bash
git clone git@github.com:Netry07/netrys-bot.git
cd netrys-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Результат:** в начале строки терминала появилось `(.venv)`, а `pip` завершился без ошибок. На Windows окружение активируется командой `.venv\Scripts\activate`.

## Шаг 4. Создайте файл `.env`

Рядом с `bot.py` создайте файл `.env`:

```text
TELEGRAM_BOT_TOKEN=сюда_токен_из_шага_1
OPENROUTER_API_KEY=сюда_ключ_из_шага_2
```

> 🔐 Файл `.env` содержит секреты. Не добавляйте его в репозиторий.

## Шаг 5. Запустите бота

```bash
python bot.py
```

**Результат:** в терминале появилась строка `Бот запущен.` и нет ошибок. Бот работает, пока открыт терминал; как оставить его работать постоянно, описано в разделе [Установка и настройка](installation.md#запуск-в-фоне).

## Шаг 6. Добавьте бота в чат

1. В BotFather выполните: `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** → **Turn off**. Без этого бот не видит обычные сообщения группы и не сможет пересказывать переписку.
2. Добавьте бота в группу. Если он уже был в ней до смены настройки, удалите его и добавьте заново.

## Шаг 7. Проверьте работу

| Что отправить | Что должно произойти |
|---|---|
| `/start` | Приветствие и список команд, в том числе блок «🎡 Колесо удачи» |
| `/count` | «📊 Запомнено сообщений: N (макс. 1000)» |
| `/wheel` | Меню колеса с кнопками |
| `/spin` | Анимация колеса и через пару секунд выпавшая игра |

Если все четыре проверки прошли, бот готов. Что делать дальше:

- как пользоваться резюме и колесом — [Руководство пользователя](user-guide.md);
