## Команды

| Команда | Аргументы | Что делает |
|---|---|---|
| `/start`, `/help` | нет | Приветствие и список команд |
| `/summary` | нет | Меню резюме переписки |
| `/count` | нет | Сколько сообщений бот помнит в этом чате |
| `/cancel` | нет | Отменяет текущий диалог (ввод числа, добавление пунктов и т. п.) |
| `/wheel` | нет | Меню активного колеса |
| `/spin` | `[название колеса]` | Крутит колесо; без аргумента активное, с аргументом указанное |
| `/tierlist` | нет | Пункты активного колеса по тирам с шансами |
| `/addgame`, `/addgames` | `[список]` | Добавляет один пункт или список в активное колесо |
| `/setweights` | `[тиры]` | Задаёт тиры и коэффициенты активного колеса |
| `/weights` | нет | Показывает коэффициенты активного колеса |
| `/wheels` | нет | Список колёс чата, переключение, удаление |
| `/newwheel` | `[название]` | Создаёт новое колесо и делает его активным |
| `/wheelstats` | нет | Статистика розыгрышей активного колеса |
| `/newevening` | нет | Возвращает в колесо все выпавшие пункты |

Аргументы в квадратных скобках необязательны: если их не указать, бот запросит их отдельным сообщением.

## Форматы ввода

### Резюме

| Поле | Формат | Ограничения |
|---|---|---|
| Количество сообщений | целое число | от 1 до 1000 |
| Период | число часов, дробное через точку или запятую | больше 0 и не больше 720 |

Стили резюме:

| Стиль | Результат |
|---|---|
| 📄 Обычное | Связный текст: о чём говорили, какие темы поднимались, были ли решения |
| • Тезисами | Короткий маркированный список, по одному предложению на пункт |
| ≡ Кратко | Один абзац на 3–4 предложения |

### Пункты колеса (`/addgame`)

Каждый пункт пишется с новой строки. Формат строки:

```text
Название
Название | Тир
```

Правила разбора:

- перед названием допускаются маркеры списка (`-`, `•`, `*`, `–`, `—`, `1.`, `1)`), бот их отбрасывает;
- тир указывается после вертикальной черты, регистр не важен;
- если у колеса один тир, пункты без тира попадают в него сразу; если тиров несколько, бот спросит кнопками;
- названия, отличающиеся только регистром, считаются одинаковыми: повтор пропускается;
- неизвестный тир или слишком длинное название превращают строку в ошибку, остальные строки добавляются.

### Тиры и коэффициенты (`/setweights`)

Формат: `Название=число`. Разделители между тирами: перенос строки, точка с запятой или запятая с пробелом. Вместо `=` допускается `:`.

```text
GOAT=16, Peak=8, Mid=4, Meh=2, Slop=1
```

Правила:

- порядок записи задаёт порядок тиров, от лучшего к худшему;
- существующие тиры обновляются, новые создаются;
- тир, которого нет в новом списке, удаляется, но только если в нём нет пунктов, иначе бот откажет и ничего не изменит;
- дробные коэффициенты записываются через точку или запятую (`0.5`, `2,5`).

## Коэффициенты и шансы

Шанс пункта равен коэффициенту его тира, делённому на сумму коэффициентов всех пунктов, которые сейчас на колесе:

```python
chance = item_weight / sum(w for w in pool_weights)
```

Пример. На колесе три пункта: «Матрица» и «Дюна» в тире «Хит» (коэффициент 10) и «Титаник» в тире «Норм» (коэффициент 2). Сумма равна 22.

| Пункт | Шанс сначала | Шанс после выпадения «Матрицы» |
|---|---|---|
| Матрица | 45,5% | исключена |
| Дюна | 45,5% | 83,3% |
| Титаник | 9,1% | 16,7% |

Выпавший пункт исключается из колеса, поэтому шансы остальных пересчитываются. Размер сектора на анимации пропорционален шансу. Подписи рисуются только на секторах шире 7°: у редких пунктов подписи нет, но сектор остаётся на колесе.

## Параметры колеса

| Параметр | Значение | Где менять |
|---|---|---|
| Тиры нового колеса | один тир «Обычный» с коэффициентом 1 | `DEFAULT_TIER` в `wheel.py` |
| Тиры колеса Jackbox | GOAT 16, Peak 8, Mid 4, Meh 2, Slop 1 | `JACKBOX_TIERS` в `wheel.py` |
| Максимум колёс в чате | 10 | `MAX_WHEELS` |
| Максимум тиров в колесе | 10 | `MAX_TIERS` |
| Максимум пунктов в колесе | 300 | `MAX_ITEMS` |
| Длина названия пункта | до 40 символов | `MAX_NAME_LEN` |
| Длина названия тира | до 20 символов | `MAX_TIER_NAME` |
| Коэффициент | больше 0, не больше 1000 | `MAX_WEIGHT` |
| Голосов для «Крутить заново» | 2 в группе, 1 в личной переписке | `REROLL_VOTES` |
| Пунктов на странице управления | 10 | `PAGE_SIZE` |
| Анимация | 40 кадров по 80 мс, размер 420×420 px | `FRAMES`, `FRAME_MS`, `IMG_SIZE` |

## Поведение бота

**Обращение к боту.** Бот проверяет каждое текстовое сообщение: это ответ на сообщение бота или в тексте есть `netrys_bot`. Если да, нейросеть определяет тон и возвращает один из вариантов: ответ на агрессию (резкий, с сарказмом), ответ на позитив (тёплый, 1–2 предложения) или пропуск для нейтрального сообщения.

**Автокомментарий.** Бот считает сохранённые текстовые сообщения чата. На каждом пятидесятом он берёт последние 10 сообщений и отправляет короткий комментарий с пометкой «💬». Счётчик хранится в памяти и обнуляется при перезапуске бота.

**Нейросеть.** Запросы идут в OpenRouter, модель задаётся параметром `MODEL`. Для реплик лимит ответа 300 токенов, для резюме 1024. Если модель «думает вслух», бот вырезает рассуждения и оставляет итоговый русский текст. Длинные резюме делятся на сообщения по 4096 символов.

**Ошибки нейросети.** При сбое резюме бот пишет «❌ Не удалось получить суммаризацию. Попробуй позже.». Реплики и автокомментарии при сбое молча пропускаются, ошибка записывается в лог.

## База данных

Бот использует один файл SQLite (`messages.db`). Таблицы создаются автоматически.

| Таблица | Назначение | Ключевые поля |
|---|---|---|
| `messages` | Сообщения чатов для резюме | `chat_id`, `sender`, `username`, `text`, `timestamp` |
| `wh_wheels` | Колёса чатов | `chat_id`, `name` |
| `wh_tiers` | Тиры колеса и их коэффициенты | `wheel_id`, `name`, `weight`, `pos` |
| `wh_items` | Пункты колеса | `wheel_id`, `name`, `tier_id`, `played` |
| `wh_spins` | История розыгрышей | `chat_id`, `wheel_id`, `item_name`, `user_name`, `ts`, `rejected` |
| `wh_chat` | Какое колесо активно в чате | `chat_id`, `active_wheel_id` |

> ⚠️ В `messages` сохраняется текст обычных сообщений (команды не сохраняются), для каждого чата хранятся только последние 1000, более старые удаляются автоматически. Данные лежат на сервере в открытом виде и передаются в OpenRouter при построении резюме.

## Примеры

Запуск бота:

```bash
source .venv/bin/activate
python bot.py
```

Назначение: запуск бота в текущем терминале. Что получится: в консоли появится строка `Бот запущен.`, бот начнёт отвечать в Telegram. Когда использовать: при первом запуске и для отладки; для постоянной работы см. [Запуск в фоне](installation.md#запуск-в-фоне).

Создание колеса с коэффициентами:

```text
/newwheel Фильмы
/setweights Хит=10, Норм=2
/addgame Матрица | Хит
Дюна | Хит
Титаник | Норм
/spin
```

Это четыре сообщения: `/newwheel`, `/setweights`, список и `/spin`. Три строки списка (`/addgame` и две следующие) отправляются одним сообщением, перенос строки внутри него делается клавишей переноса (на телефоне это обычно отдельная кнопка), а не отправкой.

Назначение: отдельное колесо для выбора фильма, где хиты выпадают в пять раз чаще обычных. Что получится: колесо «Фильмы» с тремя пунктами и анимация результата. Когда использовать: когда нужен выбор не из игр Jackbox.
