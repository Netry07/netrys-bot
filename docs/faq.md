## Частые вопросы

<details>
<summary><b>Бот не отвечает в группе, хотя в личной переписке работает</b></summary>

Скорее всего, у бота включён режим приватности и он не видит обычные сообщения группы. Отключите его: BotFather → `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** → **Turn off**. Если бот уже был в группе, удалите его и добавьте заново. Подробнее: [Установка и настройка](installation.md#установка).
</details>

<details>
<summary><b>Резюме пишет, что сообщений нет, хотя переписка была</b></summary>

Бот запоминает только сообщения, отправленные после того, как он был добавлен в чат с отключённым режимом приватности. Старую переписку он не видит. Проверьте счётчик командой `/count`.
</details>

<details>
<summary><b>Бот не реагирует, когда я к нему обращаюсь</b></summary>

Бот отвечает на ответы на его сообщения и на сообщения, где есть `netrys_bot`. На нейтральные сообщения он намеренно не отвечает. Если у бота другой username, администратор должен поменять `BOT_USERNAME` в `bot.py` (см. [параметры в коде](installation.md#параметры-в-коде)).
</details>

<details>
<summary><b>На колесе нет названий игр</b></summary>

Есть две причины. Во-первых, на сервере может не быть шрифта с кириллицей: тогда подписи отключены совсем, а результат всё равно приходит текстом (см. [требования](installation.md#требования)). Во-вторых, у редких пунктов (низкие тиры) сектор слишком узкий для подписи, это нормально.
</details>

<details>
<summary><b>Почему одна и та же игра не выпадает дважды за вечер?</b></summary>

Выпавший пункт исключается из колеса до команды `/newevening`. Если выпали все пункты, начинается новый круг сам. Если результат отклонили кнопкой «Крутить заново», пункт возвращается в колесо.
</details>

<details>
<summary><b>Как сделать колесо не для игр?</b></summary>

Создайте новое колесо командой `/newwheel Название`, добавьте пункты через `/addgame` и, если нужно, настройте шансы через `/setweights`. Пример: [Справка → Примеры](reference.md#примеры).
</details>

<details>
<summary><b>Кто видит мои сообщения?</b></summary>

Бот хранит текст сообщений чата в базе на сервере администратора. При создании резюме выбранные сообщения с именами авторов отправляются в OpenRouter. Подробности: [Справка → База данных](reference.md#база-данных).
</details>

<details>
<summary><b>Как удалить сохранённые сообщения чата?</b></summary>

Администратор сервера может удалить их командой (подставьте номер чата из лога или таблицы `messages`):

```bash
sqlite3 messages.db "DELETE FROM messages WHERE chat_id = -1001234567890;"
```

Удалять файл `messages.db` целиком не стоит: вместе с сообщениями пропадут все колёса и история розыгрышей.
</details>

## Неисправности

| Признак | Возможная причина | Что делать |
|---|---|---|
| Бот вообще не отвечает | Процесс остановлен | Проверьте процесс (см. [Диагностика](#диагностика)), при необходимости запустите заново |
| В логе `Conflict: terminated by other getUpdates request` | Запущено два экземпляра бота | Оставьте один процесс, остальные остановите |
| Команды колеса не найдены | Запущена старая версия кода | Обновите код (`git pull`) и перезапустите бота: [Обновление](installation.md#обновление) |
| «❌ Не удалось получить суммаризацию. Попробуй позже.» | Ошибка OpenRouter: лимит бесплатной модели, неверный ключ, нет сети | Посмотрите ошибку в логе (`Ошибка OpenRouter`), проверьте ключ в `.env`, повторите позже |
| Резюме приходит на английском или с рассуждениями | Модель «думает вслух» | Повторите запрос; при повторении сообщите разработчику |
| Колесо без подписей | Нет шрифта с кириллицей | Установите DejaVu или задайте `WHEEL_FONT` |
| Бот не видит сообщения в группе | Включён режим приватности | Отключите Group Privacy в BotFather и добавьте бота заново |
| Автокомментарии не приходят | Счётчик обнуляется при перезапуске, либо нейросеть вернула ошибку | Подождите 50 сообщений, при отсутствии комментариев проверьте лог на `Ошибка AI` |

## Диагностика

Команды выполняются в папке бота, права администратора не нужны.

| Что проверить | Команда | Признак нормы | При отклонении |
|---|---|---|---|
| Запущен ли бот | `ps -eo pid,user,cmd \| grep bot.py \| grep -v grep` | Один процесс с вашим `bot.py` | Ноль процессов: запустить бота. Больше одного: остановить лишние |
| Последние записи лога | `tail -n 30 bot.log` | Есть «Бот запущен.», нет traceback | Прочитать ошибку и найти её в [таблице](installation.md#сообщения-при-установке) |
| Зависимости | `.venv/bin/python -c "import telegram, PIL, openai, dotenv; print('ok')"` | Вывод `ok` | Выполнить `pip install -r requirements.txt` |
| База данных | `sqlite3 messages.db "SELECT COUNT(*) FROM messages;"` | Число без ошибок | При ошибке сделать копию файла и сообщить разработчику |
| Размер базы | `du -sh messages.db` | Единицы мегабайт | Сильный рост: проверить число чатов |

## Профилактика

| Периодичность | Операция |
|---|---|
| Ежедневно | Проверить, что процесс бота запущен, и посмотреть конец лога на ошибки |
| Еженедельно | Проверить размер `messages.db` и свободное место на диске |
| Ежемесячно | Обновить зависимости (`pip install -U -r requirements.txt`), проверить, что ключ OpenRouter не просрочен |
| После каждого обновления кода | Прогнать контрольные примеры из раздела [Проверка](installation.md#проверка) |

## Когда обращаться к разработчику

Если проблему не удалось устранить за 30 минут, а также в таких случаях:

- токен бота или ключ OpenRouter мог попасть в чужие руки (сначала отзовите токен командой `/revoke` в BotFather);
- база данных повреждена или в ней пропали данные;
- после обновления кода бот падает при запуске;
- бот отвечает странно или опасно (например, публикует личные данные).

Приложите к обращению последние строки лога и описание действий, после которых возникла проблема.
